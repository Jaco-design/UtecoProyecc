# Portafolio Web Personal - Rafely Aracena

¡Bienvenido a mi repositorio personal! Este proyecto contiene mi **Portafolio Web**, donde presento mi trayectoria, habilidades, prácticas académicas y proyectos desarrollados como estudiante de **Ingeniería de Software** en la **Universidad Tecnológica del Cibao Oriental (UTECO)**.

---

##  Tecnologías Utilizadas

* **HTML5:** Maquetación semántica, accesibilidad y optimización para buscadores (SEO básico).
* **CSS3:** Diseño responsivo con Flexbox, CSS Grid, variables personalizadas y adaptabilidad para dispositivos móviles.
* **JavaScript:** Manejo básico del DOM y redirecciones interactivas.
* **Git & GitHub:** Control de versiones, ramas y despliegue continuo.

---

##  Estructura del Proyecto

El repositorio está organizado siguiendo las mejores prácticas de la industria para proyectos web estáticos:

```text
UtecoProyecc/
│
├── index.html               # Página de inicio / Portafolio principal
├── README.md                # Presentación y documentación del repositorio
├── DOCUMENTACION.md         # Bitácora detallada de cambios técnicos y aprendizaje
├── .gitignore               # Archivos y carpetas ignorados por Git
│
├── assets/                  # Recursos multimedia y hojas de estilo
│   ├── css/
│   │   └── styles.css       # Estilos globales y responsivos
│   └── img/
│       ├── perfil.jpeg      # Fotografía de perfil
│       └── sensor.png       # Captura de pantalla del proyecto de sensor IoT
│
└── pages/                   # Páginas secundarias y prácticas
    ├── biografia.html       # Biografía personal completa
    ├── practica-js.html     # Ejercicio práctico de interacción con JavaScript
    └── complemento.html     # Página de complemento con perfil de habilidades
```

---

## Proyectos Destacados en el Portafolio

1. **Biografía Personal:**  
   Página semántica con mi perfil personal, pasatiempos y metas profesionales como futuro desarrollador de software.
2. **Sensor de Temperatura y Humedad:**  
   Integración de hardware y software utilizando **JavaScript** y **PHP** para la lectura y monitoreo en tiempo real de variables ambientales.
3. **Interacción Dinámica Web (JavaScript):**  
   Práctica de navegación e interactividad basada en eventos DOM.
